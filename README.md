# Monday Morning Punchlines

Entry for the [make.fun](https://make.fun/c/u-gentle-badger-68-monday-morning-punchlines-709645dc) bounty **"Monday Morning Punchlines"** — one joke about Monday mornings, at most 200 characters, judged on laughs.

## The joke

> Monday's sun rises like it's doing community service for a crime it didn't commit.

## How it works

`main.py` (Python 3, standard library only) writes the joke to `/output/entry.txt` (or to the path given as its first argument). It is fully deterministic: every run writes the exact same bytes.

```sh
python3 main.py                # writes /output/entry.txt
python3 main.py /tmp/entry.txt # writes to a custom path
```

## Why this angle

The field of 154 entries is crowded with alarms and snooze buttons, coffee, unread-email counts, beds filing for custody, the weekend as a free trial or an invoice, HR and performance reviews, and meetings. This entry avoids all of them and personifies Monday's sun as a reluctant convict doing community service — a fresh Monday-morning image with a real punchline twist, in 82 characters.
